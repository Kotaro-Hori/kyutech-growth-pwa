# KYUTECH GROWTH Ver.1.6 — 行動軸UI・記録改善版

## 目的
Ver.1.5をベースに、中学生が迷わず使える簡潔な画面と、選手・保護者・スタッフ・監督の連携機能を試作した版です。**本番用ではありません。**

## Windowsで開く
1. ZIPを解凍し、ファイル一式（`index.html` と `app.js` 等）を同じフォルダに置きます。
2. Anaconda Promptでそのフォルダへ移動し、`python -m http.server 8000` を実行します。
3. ブラウザで `http://localhost:8000` を開きます。

試作用ID：`player01 / Player123!`、`parent01 / Parent123!`、`staff01 / Staff123!`、`director01 / Director123!`。

## 変更点
- 選手：野球成績の打者／投手切替、シーズン集計・試合別詳細、グラフ2面と切替、短期目標の穴埋め文、練習記録の分類タグと次回行動、**試合前**メニューで分類別の過去の振り返り確認
- 保護者：ホーム名変更、選手と同様の成長画面、監督の「野球の通知表」（野球・体づくり各5段階）の閲覧
- スタッフ：ホームに「助言・トレーニング・データ入力」導線、助言メニュー、全選手／個別のトレーニング割当、スタッフ選択、種目追加・PDF／画像添付、相関散布図、測定項目の順番入力、連絡バッジ
- 監督：試合の勝敗と攻守指標（試合結果入力付き）、目標・連絡への導線、成長メニュー、スタッフと共通のデータ入力、野球の通知表作成、連絡バッジ

## 成績計算の注意
- 打率＝安打÷打数、出塁率＝（安打＋四球＋死球）÷（打数＋四球＋死球＋犠飛）
- 長打率＝（安打＋二塁打＋二×三塁打＋三×本塁打）÷打数、OPS＝出塁率＋長打率
- 走者あり三振率＝走者あり三振÷走者あり打席。**これらの入力がなければ「—」**
- 投手の防御率・奪三振率・平均被安打・平均四死球は**9イニング換算**。球数とストライク数が記録されている場合のみストライク率を表示します。
- シーズン集計は保存されている同一選手の野球成績レコードを集計します。**デモの試合記録は複数の試合を完全に網羅するとは限りません。**
- 監督ホームの勝敗・試合平均は、監督が「試合結果を入力する」で登録した試合結果だけから集計します。集計用の試合情報と選手別野球成績は、試作版では自動紐づけしていません。
- 相関散布図は直近の測定値とシーズン成績を比較する試作です。因果関係や評価を意味しません。

## 制約と重要事項
- この版は**端末内IndexedDB保存**。別デバイスのデータと同期しません。
- IDとパスワードはハードコードされた試作表示です。**本当の認証・認可・Supabase・RLSは未実装です**。
- 実際の選手、保護者、InBodyなど個人・身体情報を登録しないでください。公開リポジトリには試作コードが見えます。
- PDF／画像の添付は端末内にデータとして保存する方式です。容量上限があり、チーム全員に配信されるものではありません。
- 通知バッジも同一端末の履歴が元です。プッシュ通知ではありません。
- 測定の順次入力は「項目を1つずつ入力→最後に保存→次の選手」を想定した試作UIです。未入力項目はスキップできますが、全項目未入力で保存することはできません。
- 入力済みのブラウザでは、従来のローカル保存形式を引き継ぎます。**更新前にJSONバックアップを取得**してください。オリジン（URL）が異なると保存領域も異なります。
