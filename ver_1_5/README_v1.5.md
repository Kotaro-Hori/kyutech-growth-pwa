# KYUTECH GROWTH v1.5 — 役割別レスポンシブUI試作版

## 目的
Ver.1.4の構造とデモ記録をベースに、4つのアカウントに合ったメニュー構成と表示幅を試すためのバージョンです。

- **選手・保護者**：スマートフォン向けの縦画面・下部アイコンナビゲーション
- **スタッフ・監督**：PC向けの広い画面・左サイドメニュー
- **全アカウント**：ログイン画面から開始（テスト認証のみ）
- 端末内の試作データは従来のIndexedDBキーを維持（異なるURL間では共有されません）。

## アカウントとメニュー

| アカウント | テストID / パスワード | メニュー |
|---|---|---|
| 選手 | player01 / Player123! | ホーム / 成長 / 目標 / 記録 |
| 保護者 | parent01 / Parent123! | 練習 / 成長 / 指導方針 |
| スタッフ | staff01 / Staff123! | 指導 / 練習設定 / 成長分析 / データ管理 / 連絡 |
| 監督 | director01 / Director123! | ホーム / 目標管理 / 分析 / 指導管理 / データ管理 / 連絡 |

## 主な変更

- 選手ホームに短期目標、記録ボタン、練習カレンダー、前回の工夫、指導者コメントを表示。
- 選手「目標」で、課題・改善事項・練習の工夫を文章にして保存。スタッフと監督が同一端末の画面から確認可能。
- 選手「記録」では既存のトレーニング・振り返り入力と練習履歴をまとめて表示。
- 保護者「練習」で選手の練習方針、割当メニュー、カレンダーを表示。
- スタッフ「指導」で各選手の練習記録を確認し、助言を記録。
- スタッフ「練習設定」で既存のトレーニング割当と種目追加を利用。
- スタッフ・監督「データ管理」で3種類の記録の入力・編集、CSV出力、テンプレート出力、CSV取込、JSONバックアップを試用。
- 監督「分析」では育成分析と戦術分析の切替を用意。ただし**戦術の局面別分析は入力データ不足のため未実装**。

## Windowsで動かす

1. ZIPを展開し、解凍されたフォルダ内でAnaconda Promptを開く。
2. `python -m http.server 8000` を実行する。
3. ブラウザで `http://localhost:8000/` を開く。
4. 上記テストIDでログインする。
5. 画面幅を変える場合は、選手・保護者はブラウザの開発者ツールでスマートフォン幅（例:390px）、スタッフ・監督は幅の広いPC画面で確認する。

## CSVに関する注意点

- 対象は **野球成績 / パフォーマンス測定 / InBody** の3種類。トレーニングのCSVは現時点で未対応。
- `playerId`は画面表示名ではなく内部IDです。CSVを出力して確認してください。
- テンプレートの列名・列順を変更しないでください。
- CSV取込は**新規追加のみ**。同じ「選手ID＋日付＋区分＋対戦相手」は重複として取り込みを停止します。これにより同日の同区分で複数の正当な記録も取り込めない場合があります。
- CSVはUTF-8（BOM付）形式。取込前にJSONでバックアップしてください。
- 今回のCSV取込は操作確認用です。大量データの取込や本番用の重複判定・データ検証は、別途設計が必要です。

## 未実装 / 重要な制限

1. **本物の本人認証・アクセス権限・未成年データ保護は未実装**。デモパスワードはJavaScript内にあり公開されます。実名・実際のInBodyデータ・家庭との私的な相談は入力しないでください。
2. **クラウド同期未実装**。監督やスタッフが別端末で入力した内容は、他の端末には届きません。「共有」は同一ブラウザ・同一保存領域内での表示のみです。
3. 指導者のコメントも同一端末内のみ。本人へのプッシュ通知などはありません。
4. 防御率・球速・ストライク率の以前の架空表示は、新しい選手ホームではなく成長画面から実際の記録を確認する構成に変更。
5. PC向けレイアウトは狭い画面でも閲覧できるよう調整していますが、スタッフ・監督はPC幅を前提としています。
6. アプリをGitHub Pagesの同じURLに上書きすると、既存の試作画面も更新されます。**まず別フォルダのlocalhostで試してください。**
7. GitHub Pagesのパスに依存しない相対URLを維持しています。Service Workerのキャッシュをv1.5に変更済みです。

## 今回の内部検査

- JavaScript構文検査（node --check）
- 4アカウント計18メニューのHTML生成検査（Node VM）
- 選手の練習方針保存、指導者の助言保存、CSV解析の単体検査（Node VM）
- ブラウザ実表示の自動テストは環境のアクセス制限で実施できませんでした。Windowsのブラウザで操作を確認してください。
