# KYUTECH GROWTH Ver.1.7 — 一覧入力版

Ver.1.6から、スタッフ・監督の「データ入力」画面を改修しました。

## 変更点
- パフォーマンス測定とInBody：選手プルダウンの下に、1人分の全測定項目を一覧表示します。
- 順番送り式の1項目ずつの入力は廃止しました。
- 未測定の項目は空欄にできます。ただし、数値も原本写真もない完全な空レコードは保存しません。
- 「保存して次の選手へ」：現在の記録を保存後、選手を次の順番に切り替えます。測定日は引き継ぎ、数値欄は空欄になります。最後の選手の次は先頭の選手に戻ります。
- 「保存して終了」：現在の記録を保存し、完了画面に切り替えます。
- 保存に失敗した場合は移動しません。新規記録は既存のIndexedDB形式で保存します。
- 測定目標値の設定機能は折りたたみ欄に残しました。
- 野球成績入力、CSV、その他の役割画面は基本的にVer.1.6から維持しています。

## 確認方法
ZIPを解凍して `index.html` 等を同じ場所に置き、端末上で `python -m http.server 8000` → `http://localhost:8000` を開きます。

試作用ログイン：`staff01 / Staff123!`、`director01 / Director123!`。

データ入力 → パフォーマンス測定またはInBody → 入力 で操作を確認します。

## 重要
これは試作版です。クラウド同期、正式な認証・役割別アクセス制御、Supabaseとの接続は未実装です。データは各端末内のみ保存されます。実際の未成年者の個人情報や身体データを入力しないでください。

既に保存済みのデータを保持するため、IndexedDBの保存キーは変更していません。公開サイトを上書きする前に JSON バックアップを取得してください。URLの変更により保存領域が変わることがあります。
